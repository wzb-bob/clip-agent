# 四类素材拍摄指南

## 🎤 口播出镜（主轨）
- **用途**: 视频主轨道·真人或数字人面对镜头说话
- **拍摄**: 手机竖屏·人物居中·看镜头说话
- **格式**: MP4/MOV·1080x1920 竖屏
- **时长**: 建议10-60秒·单条完整口播

## 🏠 店铺环境（B-roll空镜）
- **用途**: B-roll覆盖·展示店面空间感
- **拍摄**: 门头全景/店内环境/特色装修/排队场景
- **格式**: MP4/MOV/JPG/PNG·建议每个2-5秒
- **数量**: 3-5个

## 📦 产品展示（B-roll覆盖）
- **用途**: B-roll覆盖·展示产品细节
- **拍摄**: 产品特写CU/制作过程/顾客使用场景
- **格式**: MP4/MOV/JPG/PNG·建议每个2-5秒
- **数量**: 3-5个

## 👉 引导CTA（结尾）
- **用途**: 视频最后一段·引导观众行动
- **拍摄**: 真人手指左下角·或文字卡片"团购已上线"
- **格式**: MP4/MOV/JPG/PNG·建议2-3秒
- **数量**: 1-2个
